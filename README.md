## 💡 Project Overview

This collection serves as an algorithmic training ground designed to improve problem-solving speed, memory optimization, and logical efficiency required for technical coding assessments and platforms like LeetCode, HackerRank, and CodeChef.

**Core Technical Focus:**
* **Mathematical & Number Theory:** Optimised prime checks, Armstrong values, Perfect numbers, and Fibonacci generation.
* **String Processing:** Two-pointer techniques, anagram verification, and frequency filtering.
* **Spatial Matrix Patterns:** Structural nested loops and spatial output generation.
* **Basic Execution Fundamentals:** Fast conditional evaluation, user inputs, and variable swapping mechanics.
